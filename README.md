# Shitcoin Swap

Shitcoin Swap is a modular open-source trading engine, developed to support all sorts of asset classes, ranging from conventional stocks via finance APIs to digital blockchain assets.

For a rationale why this project exists, please check out this [blog post](https://dev.to/buhrmi/shitcoin-society-the-quest-for-an-open-source-trading-engine-6ho). Also make sure to follow our [thread on BitcoinTalk](https://bitcointalk.org/index.php?topic=5586736) for project updates.

For cooperation and business inquiries, feel free to reach out at [hello@shitcoinswap.com]
